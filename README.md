# POLARIS — 天の北極から見る地球の自転

天の北極（地球の自転軸の北側延長線上）からの視点を中心に、地球の自転と太陽・恒星との位置関係を3Dで観察する Web アプリケーションです。

地球がなぜ反時計回りに回転して見えるのか、昼夜の境界（ターミネーター）が季節によってどう傾くのか、北極圏で白夜・極夜が生じる仕組み、恒星日（約23時間56分）と太陽日（24時間）の約4分の差、各地点で太陽が東から昇り西に沈む理由を、時刻や視点を切り替えながら直感的に観察できます。

## 主な機能

- **3D 地球儀・月・金星・太陽公転・東京の地上視点・連続視点移動**：
  - 観察視点を **地球の自転**（`天の北極` / `黄道面・水平`）、**月の公転・満ち欠け**（`天の北極・真上` / `公転面・水平`）、**太陽と地球の公転**（`太陽の真上` / `公転面・やや上`）、**東京の地上から見る空**（`北` / `東` / `南` / `西`）の 4 グループ・10 視点で整理
  - いずれの視点間も 3 次イージング（Ease-In-Out）と対数ズーム／クォータニオン slerp 補間によって、宇宙視点から東京の地上への降下や東西南北の旋回までゆっくり滑らかに連続移動
  - 東京の地上視点では、太陽高度に応じた大気スカイドーム（昼の青空・朝焼け/夕焼け・満天の星空）、地平線シルエット、8方位ラベル、高度 35.7° の北極星（ポラリス）、視差補正済みの太陽・月・金星（明けの明星・宵の明星）を描画し、北の空の反時計回り日周運動や東→南→西への動きを直感的に観察可能
  - 「天の北極 (0%) ⇄ 公転面・水平 (100%)」連続スライダーにより、地球の自転観察・月の公転観察のいずれの距離でも任意の角度へ無段階に遷移可能
  - 太陽中心にプラズマ・コロナシェーダーで描いた太陽を配置し、地球の公転に加えて、地球の内側（`0.72 AU`・約 `224.7日` 周期・傾斜角 `3.395°`）を公転する**金星**と、黄道面に対して約 `5.145°` 傾いた白道上を公転・満ち欠けする**月**を観察可能
  - マウスドラッグによる自由な視点回転（地上視点では360°の空と天頂を見渡す自由パン・チルト）、ホイールによる拡大縮小（地上視点では視野角ズーム）に対応し、左右パネルの中央空間にすっきり収まるよう自動で水平センタリングを調整
- **2つのビジュアルモード**：
  - **宇宙リアル（`realistic`）**：緯度別の気候帯カラー、夜側の街灯りの点灯、薄明（トワイライト）のグラデーション、大気リムライト、海洋の鏡面反射、恒星背景を描画
  - **天文図解（`diagram`）**：`world-atlas` と `topojson-client` によるクリーンな大陸輪郭、経緯線、北極圏（`66.6°N`）破線、昼夜境界を強調して描画
- **2つの基準フレーム**：
  - **太陽方向を固定（`solar`）**：太陽の方位を画面右側に固定し、地球の自転に伴う各地の昼夜変化と季節ごとの日照領域を観察
  - **恒星・春分点を固定（`sidereal`）**：恒星背景と春分点（`♈`）を静止させ、公転に伴う太陽の移動と恒星日・太陽日の約4分差を比較
- **時間と季節の操作**：
  - 再生・一時停止、現在時刻（「今」）への同期、6段階の倍速切り替え（自転観察向けの `1×`, `30分/s`, `2時間/s` と公転観察向けの `1日/s`, `10日/s`, `30日/s`）
  - 1恒星日（`23時間56分04秒`）および 1太陽日（`24時間`）単位のステップボタン
  - UTC 00:00〜23:59 の 1日時刻スライダーと、季節プリセット（春分・夏至・秋分・冬至）へ現在時刻から未来方向へ滑らかに時間を進める連続時間遷移
- **代表都市・北極点と月の観測**：
  - 世界7都市（東京・ロンドン・ニューヨーク・レイキャビク・トロムソ・ナイロビ・シドニー）と北極点の3Dマーカーおよびラベルを表示
  - 選択地点の現地地方太陽時、太陽高度角、太陽方位角（16方位表示）、昼・薄明・夜の区分をリアルタイム算出
  - 選択地点の地表における局所方位（東＝シアン矢印、北＝ピンク矢印、西・南）ベクトルを3D地球上に表示
  - 月のリアルタイム状態（月相、月齢目安、輝面比、白道上の黄緯）と満ち欠けイラスト、および金星のリアルタイム状態（明け/宵の明星、太陽離角、輝面比、地球距離）と距離連動の見かけの大きさ・満ち欠けイラストを「地点・天体」パネルに表示
  - 「太陽の真上」視点では、月と金星に地球に対して平行な断面補助線（地球から見える半球と裏側を分ける線）と視線ガイドを表示し、満ち欠けの仕組みを公転配置と照らし合わせて観察可能
- **インタラクティブ学習ガイド**：
  - 「東京の地上から見る空（日周運動と北極星）」「月の公転・満ち欠けと白道の傾き」「太陽の真上から見る公転と季節」「なぜ反時計回り？」「黄道面（公転面）と地軸23.4°の傾き」「夏至の白夜」「冬至の極夜」「なぜ太陽は東から昇る？」「恒星日と太陽日の差」の学習実験をワンクリックで再現

## 起動方法

開発環境は Nix Flake（[flake.nix](flake.nix) / [packages.nix](packages.nix)）で管理しています。コマンドは `nix develop` の環境内で実行してください。

1. Nix 開発シェルに入る（初回実行時は Git リポジトリ初期化および `.githooks` 設定を自動で行います）

```sh
nix develop
```

2. 依存パッケージをインストールする（未導入の場合）

```sh
npm install
```

3. 目的に応じて以下の npm スクリプトを実行する

| コマンド | 実行内容 | 用途 |
|---|---|---|
| `npm run dev` | `vite` | 開発サーバーの起動 |
| `npm run typecheck` | `tsc --noEmit` | TypeScript の型チェック |
| `npm test` | `vitest run` | 天文計算ロジックの単体テスト実行 |
| `npm run build` | `tsc --noEmit && vite build` | 型チェックと本番用バンドルの生成 |
| `npm run preview` | `vite preview` | ビルド成果物のローカル確認 |
