# POLARIS — 天の北極から見る地球の自転

**公開 Web サイト（GitHub Pages）**: https://yuttei.github.io/earth_rotation_viewer/

天の北極（地球の自転軸の北側延長線上）からの視点を中心に、地球の自転と太陽・恒星との位置関係を3Dで観察する Web アプリケーションです。

地球がなぜ反時計回りに回転して見えるのか、昼夜の境界（ターミネーター）が季節によってどう傾くのか、北極圏で白夜・極夜が生じる仕組み、恒星日（約23時間56分）と太陽日（24時間）の約4分の差、各地点で太陽が東から昇り西に沈む理由を、時刻や視点を切り替えながら直感的に観察できます。

## 主な機能

- **3D 地球儀・月・金星・太陽公転・地球から見る黄道（13星座）・観察地点の地上視点・リアル太陽系モード（水〜冥・衛星）・銀河〜銀河団スケール・連続視点移動**：
  - 観察視点を **地球の自転**（`天の北極` / `黄道面・水平`）、**月の公転・満ち欠け**（`天の北極・真上` / `公転面・水平`）、**太陽と地球の公転**（`太陽の真上` / `公転面・やや上`）、**地球から見る黄道（13星座）**（`黄道・太陽追尾` / `黄道・星座固定`）、**観察地点の地上から見る空**（`北` / `東` / `南` / `西`）、**リアル太陽系（水〜冥・衛星）**（`内惑星 (水金地火)` / `木星・4衛星` / `全体・真上` / `全体・斜め`）、**近傍恒星・銀河・宇宙の大規模構造**（`近傍恒星 (3D奥行き)` / `天の川銀河` / `天の川＆アンドロメダ` / `局部銀河群` / `銀河団 (おとめ座)` / `ラニアケア超銀河団` / `観測可能な宇宙`）の 7 グループ・23 視点で整理
  - **四季の大三角・四辺形と主要15恒星（IAU J2000.0 実座標・色・等級）**：地上視点の夜空および黄道ビューに、**春の大三角＆春の大曲線（北斗七星・アークトゥルス・スピカ・デネボラ）**、**夏の大三角（ベガ・アルタイル・デネブ）**、**秋の四辺形（ペガスス座・アンドロメダ座）＆フォーマルハウト**、**冬の大三角＆冬のダイヤモンド（シリウス・ベテルギウス・プロキオン・リゲル・アルデバラン・カペラ・ポルックス）**と12の代表星座を本当の座標・等級・表面温度カラーで配置し、主要恒星をタップして日英解説カードを表示可能
  - **近傍恒星〜観測可能な宇宙の 7 段階コズミック・スケール**：太陽系からシームレスにズームアウトして、① **近傍恒星 (3D奥行き)**（4.4光年のアルファ・ケンタウリ、8.6光年のシリウス、550光年のベテルギウス、2,600光年のデネブまで実方向×対数距離で立体配置し、地球からは平面に見える三角形の本当の3D奥行きを可視化）、② **天の川銀河**（直径約10万光年）、③ **天の川銀河とアンドロメダ銀河**（約250万光年）、④ **局部銀河群**（直径約1,000万光年）、⑤ **おとめ座銀河団**（距離約5,400万光年・ろ座銀河団・かみのけ座銀河団・グレートアトラクター方向）、⑥ **ラニアケア超銀河団**（直径約5.2億光年）、⑦ **観測可能な宇宙**（直径約930億光年・コズミック・ウェブ＆CMB球殻）の7階層を3Dで立体観察可能
  - **地球から見る黄道（13星座）と3D星座線配置**：地球中心の視差ゼロ視点から、黄金の黄道ライン（10°目盛り・進行方向矢印・4季節点）と23.4°傾いた天の赤道破線を背景に、実際の IAU J2000.0 恒星座標で描かれた **黄道12星座＋へびつかい座（13星座）** の中を太陽が移動する様子を「太陽追尾」「星座固定」の両モードで観察可能。また「太陽の真上」「公転面（やや上）」視点では公転軌道の外周3D天球面上に **黄道13星座の星（恒星点）とその点を結ぶ星座線**、および「地球→太陽→現在の星座」視線ガイドを実配置し、公転と黄道のつながりを立体的に理解可能
  - いずれの視点間も 3 次イージング（Ease-In-Out）と対数ズーム／クォータニオン slerp 補間によって、簡易版 ⇄ リアル太陽系 ⇄ 各地の地上までシームレスにゆっくり連続移動
  - **リアル太陽系モード**では、NASA JPL J2000.0 ケプラー軌道要素に基づき **水星・金星・地球（月付き）・火星・木星（主要4衛星：イオ・エウロパ・ガニメデ・カリスト付き）・土星（環付き）・天王星（縦環付き）・海王星・冥王星（約17.2°傾斜の楕円軌道）** の 9 天体を 1 AU 比例縮尺で忠実に再現。**惑星・月・木星4衛星の大きさは実際の比率**（地球の半径1に対して木星11.2など、共通の倍率で縮めて表示。太陽だけは別の縮尺で木星より大きく表示）
  - **観察地点の地上視点・カシオペア座・南十字星・年周運動**：選択中の観察地点（東京・ロンドン・ニューヨーク・トロムソ・キト・シドニー・北極点・南極点）の地表から、太陽高度に応じた大気スカイドーム、地平線シルエット、8方位ラベル、北半球では北極星とW字形の **カシオペア座**、南半球（シドニー・南極点）では天の南極と **南十字星（みなみじゅうじ座）**、赤道直下（キト）では地平線から垂直に昇り春分・秋分に真上（高度90°）を通る太陽と南北両方の星座、視差補正済みの太陽・月・金星・黄道13星座を描画。さらに **「年周運動（毎日21時固定）」モード** と **「+1ヶ月（同刻）」** ステップにより、昼夜の点滅なしに毎日21時の夜空で1ヶ月約30°ずつ移動する年周運動を滑らかに観察可能
  - 「天の北極 (0%) ⇄ 公転面・水平 (100%)」連続スライダーにより、地球の自転観察・月の公転観察のいずれの距離でも任意の角度へ無段階に遷移可能
  - **6DOF（6自由度）カメラ操作**：回転3軸（左ドラッグ／矢印キーで Yaw・Pitch、Alt+ドラッグ／`Q`・`E`／2本指ひねりで Roll）と平行移動3軸（右ドラッグ／Shift+ドラッグ／2本指移動／`W`・`A`・`S`・`D`・`R`・`F`／ホイール・ピンチで前後左右上下）に対応し、視点プリセット選択時は滑らかに基準位置へリセット
- **宇宙リアル表現（太陽方向固定）**：
  - 太陽の方位を基準に、緯度別の気候帯カラー、夜側の街灯りの点灯、薄明（トワイライト）のグラデーション、大気リムライト、海洋の鏡面反射、恒星背景を常時高精細に描画
- **すっきりとしたミニマル UI**：
  - 3D 空間を最大限に広く見せるため、メイン画面には右上の観察パネル開閉アイコンボタンと下部タイムコントロールバー（アイコンのみの再生／一時停止ボタンを含む）のみを配置し、視点移動・各種表示設定・月／金星の満ち欠け・学習ガイドをすべて「観察パネル」内へ集約
- **時間と季節の操作**：
  - 再生・一時停止（アイコンボタン・停止時は非点灯）、現在時刻への同期（アイコンボタン）、年周運動（毎日21時固定）トグル、7段階の倍速切り替え（`1×`, `30分/s`, `2時間/s`, `1日/s`, `10日/s`, `30日/s`, `1年/s`）
  - 再生速度に応じて進み方を自動スケーリングする時刻スライダーと、季節プリセット（春分・夏至・秋分・冬至）へ現在時刻から未来方向へ滑らかに時間を進める連続時間遷移
- **8つの代表観察地点（東京・ロンドン・ニューヨーク・トロムソ・キト・シドニー・北極点・南極点）と月・金星の満ち欠け・日食／月食の再現**：
  - 北半球中緯度〜北極圏〜赤道直下〜南半球〜両極の8地点の3Dマーカーおよびラベルを表示し、どの地点の地上からも北・東・南・西の空を観察可能
  - 選択地点の地表における局所方位（東＝シアン矢印、北＝ピンク矢印、西・南）ベクトルを3D地球上に表示
  - 「地点・天体」タブでは、月と金星の満ち欠けの様子の絵（リアルタイム SVG）と状態の名前（`三日月`、`満月`、`新月（皆既日食）`、`満月（皆既月食）`、`明けの明星`、`宵の明星` など）をシンプルに表示
  - **リアル太陽系N体万有引力・天体衝突シミュレーター（全10種の投入天体＆太陽系全15天体の相互衝突・軌道崩壊）**：リアル太陽系モードを舞台に、「地点・天体」タブから **小惑星・氷彗星・月サイズ・火星サイズ・木星サイズ・赤色矮星・太陽クラス恒星・青色超巨星・中性子星・ブラックホール** の10種類の天体を選択可能。それぞれ実在の天体（チクシュルーブ衝突体・ハレー彗星・月・火星・木星・プロキシマ・ケンタウリ・太陽・リゲル・かにパルサー・はくちょう座X-1）がモデルで、**重さと距離は実際の値で計算**（大きさは見える大きさに拡大し、衛星は母惑星のまわりに広げて描く）。衝突は画面に描いている位置と大きさで判定し、描いた絵どうしが触れたら当たる（青色超巨星は描く大きさが天王星の軌道の近くまであり、置いた瞬間に中の天体を飲み込むことがある）。投入天体と**太陽系の全15天体（太陽＋水金地火木土天海冥＋月＋木星4衛星イオ・エウロパ・ガニメデ・カリスト）**すべてが互いの万有引力（N体問題）でリアルタイムに運動し、全15天体のどれでも狙えるほか、**種類を混ぜて最大16個まで続けて置け（投入天体どうしも引き合い、ぶつかると強いほうが吸収。同じ天体どうし（リゲルとリゲル、月サイズと月など）は対消滅して両方消える）**、恒星や巨大天体の重力で**惑星たちの公転軌道が乱れて太陽系天体同士が連鎖的に衝突・吸収・弾き飛ばされる**様子をいつまでも観察可能。「復活」ボタンを押したタイミングで3.2秒かけて全天体が元のケプラー公転軌道へ**「ぬるっと復活」**します
  - **日食（皆既日食・金環日食・部分日食）と月食（皆既月食・部分月食・半影月食）の3D再現**：約5.1°傾いた白道と黄道の交点付近で起こる新月・満月と、月の楕円軌道（近地点・遠地点）による見かけの視直径変化に基づき、地上からの太陽コロナ／金の輪（金環）／部分欠け／赤銅色の満月（ブラッドムーン）と、宇宙から見た地球昼面の月影（本影・半影）を描画
  - **天体タップでクローズアップ＆日英解説カード表示**：3D空間上の太陽・月・9天体（水〜冥）・木星の4大衛星（太陽系15天体）と主要15恒星に加え、天の川銀河・アンドロメダ銀河・さんかく座銀河・大小マゼラン雲・局部銀河群・おとめ座銀河団・ろ座銀河団・かみのけ座銀河団・グレートアトラクター・ラニアケア超銀河団・観測可能な宇宙（全41天体・構造の本体またはラベル）をタップすると、適切なサイズへ滑らかにズームイン／ズームアウトし、PC・タブレットでは画面左に天体・右に詳細解説カード（スマホ縦画面では上に天体・下に解説カード）を表示。各天体のイラスト・基本データ・日本語の説明文・**中学英語レベルの説明文**を確認でき、ドラッグ回転・ズームや「×」での元の視点への滑らかな復帰にも対応
  - **実績（体験チェックリスト）**：地球の自転・地上の空・月と食・太陽系・天体図鑑・宇宙の大きさ・天体衝突シミュレーターの7分類22個の「やってみてほしい操作」を、観察パネルの「実績」タブに達成状況と進捗（n/22）つきで一覧表示。未達成の実績も「やること」を表示して次の操作を案内し、達成した瞬間は画面上部に「実績解除：◯◯」を約3秒表示。記録はブラウザ（localStorage）に保存され、再読み込み後も残り、「記録を消す」でリセット可能
  - 「太陽の真上」視点では、上＝春分・左＝夏至・下＝秋分・右＝冬至（地軸が右傾き）の配置で、月と金星に地球に対して平行な断面補助線（地球から見える半球と裏側を分ける線）と視線ガイドを表示し、満ち欠けの仕組みを公転配置と照らし合わせて観察可能
  - 「月の公転・満ち欠け」の「天の北極・真上」視点では、白道の上に **新月・上弦・満月・下弦** の4つの目印と、地球から太陽の方向を示す線を表示。4点は太陽の向きに合わせて回り、地球-月の線と太陽方向の線のなす角（月相角）から、いまの月がどの満ち欠けにあるかを読み取れる
- **インタラクティブ学習ガイド（全16テーマ・開閉式カード）**：
  - 地球の自転・日の出・地軸の傾き・白夜/極夜・公転と季節・地上星空・年周運動・**四季の星座と1等星**・黄道13星座・月の満ち欠け・日食3種類・月食3種類・金星の満ち欠け・リアル太陽系・冥王星が準惑星である理由・**宇宙の階層（近傍恒星→天の川銀河→アンドロメダ銀河→局部銀河群→おとめ座銀河団→ラニアケア超銀河団→観測可能な宇宙の7段階）**の16テーマを適切な学習順に配置し、視点と時間の滑らかな連続移動でワンクリック再現
- **スマートフォン（iPhone 17）・タブレット（iPad A16 縦/横）対応**：
  - `viewport-fit=cover` と `env(safe-area-inset-*)` によりノッチ／Dynamic Island・ホームバーを回避し、iPhone 17（`402×874` / 横 `874×402`）・iPad A16 縦（`820×1180`）・iPad A16 横（`1180×820`）それぞれに最適化した 4 段階レスポンシブレイアウトを採用

  - 1本指ドラッグによる視点回転・2本指ピンチイン／ピンチアウトによる拡大縮小に対応し、同一 Wi-Fi 上のスマホ・タブレットから `--host 0.0.0.0` でプレビュー可能

## 起動方法

開発環境は Nix Flake（[flake.nix](flake.nix) / [packages.nix](packages.nix)）で管理しています。コマンドは `nix develop` の環境内で実行してください。

1. Nix 開発シェルに入る（初回実行時は Git リポジトリ初期化および `.githooks` 設定を自動で行います）

```sh
nix develop
```

2. 依存パッケージをインストールする（未導入の場合）

```sh
npm install
```

3. 目的に応じて以下の npm スクリプトを実行する

| コマンド | 実行内容 | 用途 |
|---|---|---|
| `npm run dev` | `vite` | 開発サーバーの起動 |
| `npm run typecheck` | `tsc --noEmit` | TypeScript の型チェック |
| `npm test` | `vitest run` | 天文計算ロジックの単体テスト実行 |
| `npm run build` | `tsc --noEmit && vite build` | 型チェックと本番用バンドルの生成 |
| `npm run preview` | `vite preview` | ビルド成果物のローカル確認 |
