# POLARIS — 天の北極から見る地球の自転

天の北極（地球の自転軸の北側延長線上）からの視点を中心に、地球の自転と太陽・恒星との位置関係を3Dで観察する Web アプリケーションです。

地球がなぜ反時計回りに回転して見えるのか、昼夜の境界（ターミネーター）が季節によってどう傾くのか、北極圏で白夜・極夜が生じる仕組み、恒星日（約23時間56分）と太陽日（24時間）の約4分の差、各地点で太陽が東から昇り西に沈む理由を、時刻や視点を切り替えながら直感的に観察できます。

## 主な機能

- **3D 地球儀・月・金星・太陽公転・地球から見る黄道（13星座）・観察地点の地上視点・リアル太陽系モード（水〜冥・衛星）・連続視点移動**：
  - 観察視点を **地球の自転**（`天の北極` / `黄道面・水平`）、**月の公転・満ち欠け**（`天の北極・真上` / `公転面・水平`）、**太陽と地球の公転**（`太陽の真上` / `公転面・やや上`）、**地球から見る黄道（13星座）**（`黄道・太陽追尾` / `黄道・星座固定`）、**観察地点の地上から見る空**（`北` / `東` / `南` / `西`）、**リアル太陽系（水〜冥・衛星）**（`内惑星 (水金地火)` / `木星・4衛星` / `全体・真上` / `全体・斜め`）の 6 グループ・16 視点で整理
  - **地球から見る黄道（13星座）と星座イラスト**：地球中心の視差ゼロ視点から、黄金の黄道ライン（10°目盛り・進行方向矢印・4季節点）と23.4°傾いた天の赤道破線を背景に、実際の IAU J2000.0 恒星座標で描かれた **黄道12星座＋へびつかい座（13星座）** と星図イラストの中を太陽が移動する様子を「太陽追尾」「星座固定」の両モードで観察可能。また「太陽の真上」「公転面（やや上）」視点では公転軌道の外周に **黄道13星座の星図イラストメダリオン** と「地球→太陽→現在の星座」視線ガイドを配置し、公転と黄道のつながりを直感的に理解可能
  - いずれの視点間も 3 次イージング（Ease-In-Out）と対数ズーム／クォータニオン slerp 補間によって、簡易版 ⇄ リアル太陽系 ⇄ 各地の地上までシームレスにゆっくり連続移動
  - **リアル太陽系モード**では、NASA JPL J2000.0 ケプラー軌道要素に基づき **水星・金星・地球（月付き）・火星・木星（主要4衛星：イオ・エウロパ・ガニメデ・カリスト付き）・土星（環付き）・天王星（縦環付き）・海王星・冥王星（約17.2°傾斜の楕円軌道）** の 9 天体を 1 AU 比例縮尺で忠実に再現
  - **観察地点の地上視点・カシオペア座・南十字星・年周運動**：選択中の観察地点（東京・ロンドン・ニューヨーク・トロムソ・シドニー・北極点・南極点）の地表から、太陽高度に応じた大気スカイドーム、地平線シルエット、8方位ラベル、北半球では北極星とW字形の **カシオペア座**、南半球（シドニー・南極点）では天の南極と **南十字星（みなみじゅうじ座）**、視差補正済みの太陽・月・金星・黄道13星座を描画。さらに **「年周運動（毎日21時固定）」モード** と **「+1ヶ月（同刻）」** ステップにより、昼夜の点滅なしに毎日21時の夜空で1ヶ月約30°ずつ移動する年周運動を滑らかに観察可能
  - 「天の北極 (0%) ⇄ 公転面・水平 (100%)」連続スライダーにより、地球の自転観察・月の公転観察のいずれの距離でも任意の角度へ無段階に遷移可能
  - **6DOF（6自由度）カメラ操作**：回転3軸（左ドラッグ／矢印キーで Yaw・Pitch、Alt+ドラッグ／`Q`・`E`／2本指ひねりで Roll）と平行移動3軸（右ドラッグ／Shift+ドラッグ／2本指移動／`W`・`A`・`S`・`D`・`R`・`F`／ホイール・ピンチで前後左右上下）に対応し、視点プリセット選択時は滑らかに基準位置へリセット
- **宇宙リアル表現（太陽方向固定）**：
  - 太陽の方位を基準に、緯度別の気候帯カラー、夜側の街灯りの点灯、薄明（トワイライト）のグラデーション、大気リムライト、海洋の鏡面反射、恒星背景を常時高精細に描画
- **すっきりとしたミニマル UI**：
  - 3D 空間を最大限に広く見せるため、メイン画面には右上の「観察パネル」開閉ボタンと下部タイムコントロールバーのみを配置し、視点移動・観測日時／季節テレメトリ・各種表示設定・学習ガイドをすべて「観察パネル」内へ集約
- **時間と季節の操作**：
  - 再生・一時停止、現在時刻（「今」）への同期、年周運動（毎日21時固定）トグル、7段階の倍速切り替え（`1×`, `30分/s`, `2時間/s`, `1日/s`, `10日/s`, `30日/s`, `1年/s`）
  - 再生速度（`1×`〜`1年/s`）に応じてレンジと進み方を `1日` / `1ヶ月` / `1年` / `50年` に自動スケーリングする時刻スライダーと、季節プリセット（春分・夏至・秋分・冬至）へ現在時刻から未来方向へ滑らかに時間を進める連続時間遷移
- **7つの代表観察地点（東京・ロンドン・ニューヨーク・トロムソ・シドニー・北極点・南極点）と月・金星・黄道の観測**：
  - 北半球中緯度〜北極圏〜南半球〜両極の7地点の3Dマーカーおよびラベルを表示し、どの地点の地上からも北・東・南・西の空を観察可能
  - 選択地点の現地地方太陽時、太陽高度角、太陽方位角（16方位表示）、昼・薄明・夜の区分をリアルタイム算出
  - 選択地点の地表における局所方位（東＝シアン矢印、北＝ピンク矢印、西・南）ベクトルを3D地球上に表示
  - 月のリアルタイム状態（月相、月齢目安、輝面比、白道上の黄緯）と満ち欠けイラスト、および金星のリアルタイム状態（明け/宵の明星、太陽離角、輝面比、地球距離）と距離連動の見かけの大きさ・満ち欠けイラストを「地点・天体」パネルに表示
  - 「太陽の真上」視点では、月と金星に地球に対して平行な断面補助線（地球から見える半球と裏側を分ける線）と視線ガイドを表示し、満ち欠けの仕組みを公転配置と照らし合わせて観察可能
- **インタラクティブ学習ガイド**：
  - 「リアル太陽系（水〜冥・衛星）」「なぜ冥王星は『惑星』ではなく『準惑星』なの？（国際天文学連合の3条件と ○ / ○ / ✕ 比較）」「東京の地上から見る空（日周運動と北極星）」「月の公転・満ち欠けと白道の傾き」「金星の公転と明けの明星・宵の明星」「太陽の真上から見る公転と季節」「なぜ反時計回り？」「黄道面（公転面）と地軸23.4°の傾き」「夏至の白夜」「冬至の極夜」「なぜ太陽は東から昇る？」「恒星日と太陽日の差」の学習実験をワンクリックで再現
- **スマートフォン（iPhone 17）・タブレット（iPad A16 縦/横）対応**：
  - `viewport-fit=cover` と `env(safe-area-inset-*)` によりノッチ／Dynamic Island・ホームバーを回避し、iPhone 17（`402×874` / 横 `874×402`）・iPad A16 縦（`820×1180`）・iPad A16 横（`1180×820`）それぞれに最適化した 4 段階レスポンシブレイアウトを採用
  - スマホおよびタブレット縦向きでは「視点移動」カードと「観察パネル」を初期状態で折り畳み、3D キャンバスを広く確保（1タップ展開・選択後自動格納）。タブレット横向きでは1行ヘッダー＆1行コントロールバー＋左右サイドパネルで広々と操作可能
  - 1本指ドラッグによる視点回転・2本指ピンチイン／ピンチアウトによる拡大縮小に対応し、同一 Wi-Fi 上のスマホ・タブレットから `--host 0.0.0.0` でプレビュー可能

## 起動方法

開発環境は Nix Flake（[flake.nix](flake.nix) / [packages.nix](packages.nix)）で管理しています。コマンドは `nix develop` の環境内で実行してください。

1. Nix 開発シェルに入る（初回実行時は Git リポジトリ初期化および `.githooks` 設定を自動で行います）

```sh
nix develop
```

2. 依存パッケージをインストールする（未導入の場合）

```sh
npm install
```

3. 目的に応じて以下の npm スクリプトを実行する

| コマンド | 実行内容 | 用途 |
|---|---|---|
| `npm run dev` | `vite` | 開発サーバーの起動 |
| `npm run typecheck` | `tsc --noEmit` | TypeScript の型チェック |
| `npm test` | `vitest run` | 天文計算ロジックの単体テスト実行 |
| `npm run build` | `tsc --noEmit && vite build` | 型チェックと本番用バンドルの生成 |
| `npm run preview` | `vite preview` | ビルド成果物のローカル確認 |
